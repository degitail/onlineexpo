RULES

投票バトル参加作品から TOP3 を決めます

作品を応募する

日程

募集・投票期間2026年11月2日（月）〜 11月30日（月）23:59
結果発表2026年12月1日（火）

応募は期間中いつでもできます。運営が内容を確認してから掲載します（掲載まで最大1日ほどかかります）。

参加方法

応募フォームの「投票バトルに参加する」にチェックを入れた作品が対象です。チェックしない場合は展示のみとなり、順位はつきません。

審査

次の3つを 3：3：4（30%・30%・40%）の割合で合計し、上位3作品を決めます。

審査割合内容
Claude Code30%AIが作品を実際に確認し、100点満点で採点
ChatGPT30%AIが作品を実際に確認し、100点満点で採点
来場者の投票40%投票ポイントに従って換算

Claude Code と ChatGPT は、互いの採点理由を見せ合って協議したうえで最終点を出します。採点の観点は「アイデア」「完成度」「生成AIの使い方」の3つです。

投票

  • 投票は各作品のページの「投票する」から。1人1作品まで
  • 11月30日 23:59 を過ぎた票は数えません
  • 不正な投票（同じ人による複数アカウントでの投票など）が見つかった場合、その票を無効にします

同点のとき

票数が多い作品を上位とします。
